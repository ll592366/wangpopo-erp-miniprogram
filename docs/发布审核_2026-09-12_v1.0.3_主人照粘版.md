| 字段 | 填什么 |
|------|--------|
| **服务类目** | 工具 → **效率** （或企业管理 → 通用） |
| **标签**（多个） | `企业管理` `效率` `库存管理` `内部工具` |

| **功能页面截图** | 截图 5 张：登录 / 管理首页（带角标）/ 采购入库 / 申请处理 / 库存预警（单卡） |
